**BREAKING:** the `--api-key` command-line flag is removed — the key is read from `OPENZYN_API_KEY` only, because argv is world-readable in `ps` output and lands in shell history. The server now validates `OPENZYN_BASE_URL`/`--base-url` at startup: plain `http://` is rejected for non-loopback hosts (the API key is a bearer token on every request), and the optional `OPENZYN_MCP_ALLOWED_HOSTS` allowlist restricts the accepted hosts — listing a host also opts it into plain HTTP with a loud warning.
